# 🔥 Featured Engineering Work

## 💳 Money Movement & Double-Entry Ledger

A production-style financial backend built to explore the engineering problems that make money movement systems difficult: **correctness, atomicity, concurrency, idempotency, and reconciliation**.

### Engineering highlights

* Double-entry ledger with database-enforced invariants
* Atomic money transfers using PostgreSQL transactions
* Idempotency protection for duplicate and concurrent requests
* Concurrency-safe account updates using row-level locking
* Immutable ledger history enforced at the database level
* Exact money representation using integer minor units
* Deadlock-aware locking strategy
* Failure-safe PostgreSQL connectivity and graceful degradation
* Strict TypeScript configuration
* Unit and integration testing, including concurrent transaction scenarios

**Tech**

`TypeScript` `Fastify` `PostgreSQL` `Docker` `Vitest` `Pino`
